セキュマネ英語略称 暗記ノート

アルファベット3文字を記号として覚えず、正式名称・英単語の意味・語呂・役割をつなげて覚えるための教材です。

まず、この順番で覚える

① 正式名称を見る → ② 英単語の意味を拾う → ③ 役割を一言にする → ④ 語呂で固定する

例：IPSなら、Prevention＝防止が入っているので「止める側」。IDSはDetection＝検知なので「見つける側」です。

覚えるときの合言葉
Detect＝見つける／Prevent＝防ぐ／Respond＝対応する／Manage＝管理する／Authenticate＝本人確認／Authorize＝許可する

攻撃を見つける・止める・調べる

IDS検知
Intrusion Detection System
イントルージョン・ディテクション・システム
Intrusion＝侵入、Detection＝検知
覚え方：DはDetectのD。「侵入を見つけて知らせる」
不審な通信を検知して、管理者へ通知する。
IPS遮断
Intrusion Prevention System
イントルージョン・プリベンション・システム
Prevention＝防止
覚え方：PはPreventのP。「侵入を防いで止める」
不正な通信を検知し、自動的に遮断する。
WAFWeb専門
Web Application Firewall
ウェブ・アプリケーション・ファイアウォール
Web Application＝Webアプリ、Firewall＝防火壁
覚え方：名前どおり「Webアプリの前に立つ壁」
SQLインジェクションやXSSなど、Webアプリへの攻撃を防ぐ。
EDR端末で対応
Endpoint Detection and Response
エンドポイント・ディテクション・アンド・レスポンス
Endpoint＝PCなどの端末、Response＝対応
覚え方：「端末で見つけて、対応する」
PCの不審な動作を検知し、調査・隔離する。
SIEMログの司令塔
Security Information and Event Management
セキュリティ・インフォメーション・アンド・イベント・マネジメント
Information / Event＝情報・出来事、Management＝管理
覚え方：「セキュリティ情報とイベントをまとめて管理」
複数機器のログを集め、相関分析して異常を見つける。
SOC監視チーム
Security Operation Center
セキュリティ・オペレーション・センター
Operation＝運用、Center＝拠点
覚え方：「セキュリティ運用の監視室」
24時間体制などでログ監視や初動対応を行う組織。
CSIRT事故対応チーム
Computer Security Incident Response Team
コンピュータ・セキュリティ・インシデント・レスポンス・チーム
Incident Response＝事故対応
覚え方：最後がResponse Team。「事故が起きたら動く班」
インシデントの調査、封じ込め、復旧、再発防止を行う。
UTMまとめて防御
Unified Threat Management
ユニファイド・スレット・マネジメント
Unified＝統合された、Threat＝脅威
覚え方：「脅威対策を1台に統合」
FW、アンチウイルス、IDS/IPSなどをまとめて提供する。

通信・ネットワーク

VPN仮想専用線
Virtual Private Network
バーチャル・プライベート・ネットワーク
Virtual＝仮想、Private＝専用・私的
覚え方：「公共のネット上に、仮想の専用通路」
自宅から社内ネットワークへ安全に接続する。
TLS通信暗号化
Transport Layer Security
トランスポート・レイヤー・セキュリティ
Transport Layer＝通信を運ぶ層、Security＝安全
覚え方：「運ぶ途中を安全にする」
HTTPSの通信内容を暗号化する。
SSL旧称
Secure Sockets Layer
セキュア・ソケッツ・レイヤー
Secure＝安全な
覚え方：現在は主にTLS。SSLという呼び方だけ残る場面が多い。
「SSL証明書」と呼ばれていても、実際の通信はTLSであることが多い。
DNS名前→住所
Domain Name System
ドメイン・ネーム・システム
Domain Name＝Web上の名前
覚え方：「ドメイン名をIPアドレスへ案内する住所録」
example.comをIPアドレスへ変換する。
DHCPIP自動配布
Dynamic Host Configuration Protocol
ダイナミック・ホスト・コンフィギュレーション・プロトコル
Dynamic＝動的、Configuration＝設定
覚え方：「端末設定を動的に配る」
PCへIPアドレスなどを自動設定する。
IPsecIP通信を保護
Internet Protocol Security
インターネット・プロトコル・セキュリティ
IP通信をSecurityで守る
覚え方：「IP＋security」
VPNなどで、IPパケットを暗号化・認証する。

本人確認・権限・証明書

MFA複数要素
Multi-Factor Authentication
マルチ・ファクター・オーセンティケーション
Multi＝複数、Factor＝要素、Authentication＝認証
覚え方：「複数の要素で本人確認」
パスワード＋スマホ認証など。
SSO一度でログイン
Single Sign-On
シングル・サインオン
Single＝一度・単一
覚え方：「1回サインインしたら複数サービスへ」
社内ポータルへログイン後、複数の業務システムを利用する。
OTP一回限り
One-Time Password
ワンタイム・パスワード
One-Time＝一度きり
覚え方：そのまま「一回だけのパスワード」
認証アプリに表示される短時間だけ有効なコード。
PKI公開鍵の基盤
Public Key Infrastructure
パブリック・キー・インフラストラクチャ
Public Key＝公開鍵、Infrastructure＝基盤
覚え方：「公開鍵を安全に使うための社会基盤」
電子証明書、認証局、失効管理などを含む仕組み。
CA証明書を発行
Certificate Authority
サーティフィケート・オーソリティ
Certificate＝証明書、Authority＝権威ある機関
覚え方：「証明書を出す公的な係」
電子証明書を発行し、公開鍵の持ち主を保証する。
CRL失効一覧
Certificate Revocation List
サーティフィケート・レボケーション・リスト
Revocation＝取消し・失効、List＝一覧
覚え方：「使ってはいけない証明書リスト」
秘密鍵漏えいなどで無効になった証明書を掲載する。

組織・管理・監査

ISMS管理の仕組み
Information Security Management System
インフォメーション・セキュリティ・マネジメント・システム
情報セキュリティを継続的にManagementする仕組み
覚え方：「情報セキュリティを会社として回す仕組み」
方針、リスク評価、対策、監査、改善を継続する。
PDCA改善サイクル
Plan・Do・Check・Act
プラン・ドゥ・チェック・アクト
計画・実行・評価・改善
覚え方：「計画して、やって、見て、直す」
ISMSを継続的に改善する基本サイクル。
SLAサービス品質の約束
Service Level Agreement
サービス・レベル・アグリーメント
Agreement＝合意・契約
覚え方：「サービス水準についての約束」
稼働率99.9％、問い合わせ対応時間などを定める。
NDA秘密保持
Non-Disclosure Agreement
ノン・ディスクロージャー・アグリーメント
Disclosure＝開示、Non＝しない
覚え方：「開示しない約束」
業務で知った秘密情報を第三者へ漏らさない契約。
PII個人を特定
Personally Identifiable Information
パーソナリー・アイデンティファイアブル・インフォメーション
Identifiable＝特定できる
覚え方：「その人だと識別できる情報」
氏名、住所、メールアドレスなど、個人を識別できる情報。
DLP漏えい防止
Data Loss Prevention
データ・ロス・プリベンション
Data Loss＝データ損失・流出、Prevention＝防止
覚え方：「データが外へ出るのを防ぐ」
機密ファイルのメール添付やUSBコピーを制御する。

事業継続・復旧

BCP継続の計画
Business Continuity Plan
ビジネス・コンティニュイティ・プラン
Business Continuity＝事業継続、Plan＝計画
覚え方：「災害時にも事業を続ける計画」
代替拠点、連絡網、優先業務、復旧手順などを決める。
BCM継続の管理
Business Continuity Management
ビジネス・コンティニュイティ・マネジメント
Management＝管理・運用
覚え方：BCPを作るだけでなく、訓練・見直しまで回す。
BCPを継続的に整備し、訓練し、改善する活動全体。
RTOいつまでに復旧
Recovery Time Objective
リカバリー・タイム・オブジェクティブ
Recovery Time＝復旧時間、Objective＝目標
覚え方：TはTime。「復旧まで何時間？」
障害発生から4時間以内に業務を再開する。
RPOどこまで戻す
Recovery Point Objective
リカバリー・ポイント・オブジェクティブ
Recovery Point＝復旧時点
覚え方：PはPoint。「何時点のデータまで戻せればよい？」
最大1時間前のデータまで戻せればよい。

紛らわしい用語を一気に比較

用語決め手になる英単語一言で
IDSDetection見つけて知らせる
IPSPrevention見つけて止める
EDREndpoint / ResponsePCで検知・対応
SIEMInformation / Event / Managementログを集めて分析
SOCOperation Center監視する組織
CSIRTIncident Response Team事故対応チーム
BCPPlan事業継続の計画
BCMManagement計画を運用・改善
RTOTime復旧までの時間
RPOPoint戻すデータの時点
最優先で覚える4組
IDSとIPS／SOCとCSIRT／BCPとBCM／RTOとRPO
IDSとIPSの覚え分け

D＝Detection＝検知、P＝Prevention＝防止。問題文に「通知」ならIDS、「遮断」ならIPSを疑います。

SOCとCSIRTの覚え分け

SOCは日常的に監視、CSIRTは事故が起きたときに対応。見張り番と消防隊の違いです。

RTOとRPOの覚え分け

T＝Time＝時間、P＝Point＝時点。RTOは「何時間で復旧」、RPOは「何時点まで戻す」です。

確認問題

見出しから答えを推測できないよう、問題文だけで判断してください。

第1問

不審な通信を検知し、管理者へ通知するが、自動遮断はしない仕組みはどれか。

第2問

複数の機器からログを集め、関連付けて分析する仕組みはどれか。

第3問

障害発生後、業務を何時間以内に再開するかという目標を表すものはどれか。

第4問

インシデントの調査、封じ込め、復旧、再発防止を担当するチームはどれか。

第5問

パスワードに加えてスマホ認証など、複数の要素で本人確認を行う方式はどれか。

まだ採点していません。

最後に

略称を見て思い出せないときは、まず最後の英単語を探してください。
Detection、Prevention、Response、Management、Plan、Time、Pointは特に強い手掛かりです。
